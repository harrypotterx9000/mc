# 运行时分析（research/runtime-analysis）

> 汇总两轮 REA 运行时探针（无头 Edge + CDP）与用户原版试玩结果。
> 运行时探针是在原站页面里跑的；本项目试玩是本地独立副本。

## 1. 探针环境

- 无头 Edge 156，CDP `:9333`，`--use-angle=swiftshader`（CPU 光栅化，不代表真机性能）
- 通过 iframe target 直接调用游戏全局对象（`game.createWorld`、`runCommand`、`EnderDragon.hurtPart`）

## 2. 已验证事实

| 项 | 结果 |
|---|---|
| 世界创建 | `createWorld` → 1.1 s 进入 `play`，61 区块 |
| 世界生成 | 35 密度函数、15 路由槽、66 群系、4 步地表规则；区块生成约 70 ms |
| 结构 | `/locate` 命中村庄 `(-160,843)`、试炼密室 `(97,84)`、古城 `(-637,-1521)`；`monument`/`end_city` 无 |
| 区块存储 | 1,656 段中 952 段全空气（57.5%）；方块数据 47 KB/区块（扁平等价 393 KB） |
| 末影龙 | 200 HP、10 水晶、6 命中盒、头 ×1.0 / 其余 ×0.25+1、栖息 >50 强制起飞、200 tick 死亡 |
| 通关 | 22 次命中击杀 → 返回门 37 块 + 龙蛋 + 首次 12,000 经验 + `the_end`/`free_end` → 终末之诗 |
| 光影 | 2/4 档 `fx.ok=true`；SwiftShader 下 8 / 4 fps（不代表手机） |
| 触屏 | 开启后出现摇杆/跳跃/功能按钮，GUI 592×307 |

## 3. 本地独立副本试玩（用户）

- 时间：2026-11-06
- 方式：Edge 打开 `http://127.0.0.1:8080/`
- 结果：**用户确认"试玩完成，无问题"**
- 覆盖：加载、主菜单、创建/加载世界、移动、视角、破坏/放置、背包、物品、设置、存档、刷新恢复
- 未覆盖：多人、手机真机、长时间运行、性能测量

## 4. 仍未确认

- 真实 GPU 上的光影编译与帧率
- 手机/平板真机触控、发热、内存
- 多人协议与自建服务器
- 音效包缺失下的听感（当前合成音）
