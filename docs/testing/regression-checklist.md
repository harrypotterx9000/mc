# 回归检查清单（testing/regression-checklist）

> 每个阶段结束前逐项执行；未执行的项标 **NOT TESTED**，不得默认通过。

## A. 启动与加载

- [ ] `node scripts/serve.mjs` 启动无报错，`http://127.0.0.1:8080/` 返回 200
- [ ] 90 个 `js/*.js` 全部 200（控制台无 404，除已知音效包）
- [ ] 标题界面出现，背景世界渲染正常
- [ ] 控制台无新增红色错误

## B. 单人核心

- [ ] 创建世界（gen2）并进入
- [ ] 移动 / 跳跃 / 视角 / 冲刺
- [ ] 破坏方块、放置方块
- [ ] 背包打开、拿取、移动、丢弃
- [ ] 2×2 与工作台合成
- [ ] 熔炉/箱子可用
- [ ] 保存退出 → 刷新 → 世界仍在

## C. 阶段相关

- [ ] 本阶段删除的入口不再出现（逐项对照 PROJECT_SPEC §6）
- [ ] 本阶段新增/修改的功能可用
- [ ] 相关跨模块补丁未被破坏（见 `research/dependency-analysis.md`）

## D. 联机（有服务器后）

- [ ] 创建房间 → 邀请码加入
- [ ] 两名玩家看到彼此、方块同步
- [ ] 玩家退出/重进
- [ ] 服务器重启后世界恢复

## E. 性能（真实设备）

- [ ] 电脑 1080p 目标 60 FPS（记录 F3 的 p50/p95）
- [ ] 手机目标 30 FPS（记录机型、画质档）
- [ ] 光影 0/2/4 档对比记录
