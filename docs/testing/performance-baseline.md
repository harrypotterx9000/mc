# 性能基线（testing/performance-baseline）

> **当前状态：NOT MEASURED（未在真实设备测量）**。
> 本文件记录测量方法与目标；填入真实数据前，不得在任何报告中声称达到性能目标。

## 目标

| 端 | 目标 | 备注 |
|---|---|---|
| 电脑 | 60 FPS | 1080p，默认画质 |
| 手机 | 30 FPS（中高端争取 60） | 记录机型与画质档 |
| 服务器 | 20 TPS | 多人世界逻辑调度 |

## 测量方法（待执行）

1. 电脑：Edge 打开 `http://127.0.0.1:8080/`，进入同一存档同一位置（建议种子固定）。
2. 打开 F3：记录 `FPS / p50 / p95 / 最慢`、区块数、显存、动态分辨率。
3. 按 F3+L 生成 10 秒性能报告，存档到 `docs/testing/`。
4. 依次测光影 0（关）/2（中）/4（极限），每档稳定 60 s 后记录。
5. 手机：同一 URL（局域网），记录机型、系统、浏览器版本、画质档、10 分钟平均 FPS 与发热情况。
