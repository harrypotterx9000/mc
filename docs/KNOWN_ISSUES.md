## 兼容性注意事项

- 单人存档 `mc-js-clone` 的 `worlds/chunks` 结构保持；旧世界可继续读。
- 旧存档的 `meta.tutorial` 保留原值；**仅新世界**默认关教程。
- 阶段 1 中皮肤/披风/装饰的内部解锁条件已在 **phase-02 移除**；18 款皮肤、23 款披风（含 13 款管理员、3 款活动）、3 帽子、1 宠物、1 前缀全部可穿戴。
- **phase-03 起无账号**：`mcjs-look` 是唯一外观存储；不再有 `Account.data.skin` 回退或登录同步。
- 多人身份只有昵称 + 服务器临时 ID；旧 `mcjs-account`/`cloud` 元数据为死数据。
- **房间所有权不能用昵称推断**（K-47）：同名昵称会误判；phase-05 必须用服务端身份。
- 本地 P2P 主机的临时 ID 仍是 provisional（K-42），不能视为服务器签发身份。
- `p2p`/`net` 的 Monkey Patch 与 `DB` 拦截不能在未替换前直接删文件。
- `cloud` 元数据、`mcjs-cloud-dirty-*` 不主动删；每月清理前先备份。
- 遥测模块已整体移除（K-27）；旧 `settings.telemetry` 键成为死数据，不读取。
