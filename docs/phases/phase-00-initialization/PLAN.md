## 目标

在不改动游戏功能的前提下，把原版源码变成可独立运行、可版本管理、文档齐全的项目基线。

## 步骤

1. 检查原始源码与 Git 关联（`D:\ds\REA\opusmc`、`C:\Users\a\Desktop\git`）。
2. 备份原始源码（zip + SHA-256 清单）。
3. 建立 `D:\Projects\OpusMC`，保持原始目录结构，建立独立 Git。
4. 提供 Edge 本地启动方式，由用户实际试玩。
5. 按用户反馈修复 Bug（本次无）。
6. 源码与依赖复核。
7. 建文档体系与基线 `v0.1.0-preproject`。
8. 建 `main`/`develop` 分支与阶段策略。
9. 检查 GitHub 认证状态并给出安全指引。

## 验收

- 原始源码可完整恢复（zip + tag）
- 本地可启动、用户试玩通过
- 文档、Git、测试一致
