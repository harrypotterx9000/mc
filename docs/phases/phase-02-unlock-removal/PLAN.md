## 1. 目标

1. 所有皮肤、披风、装饰不需要解锁条件，包括 `adm*` 管理员披风和签到活动款。
2. 保留皮肤预览、切换、渲染、装饰选择、披风显示、外观保存与恢复。
3. 不只隐藏锁定图标：修改真正的权限判断。
4. 多人游戏入口不再要求登录 / 关注 / 三连 / 识别码；房间加入仍走邀请码 / 房间服务校验。
5. 只做本阶段，不进入 phase-03，不重写无关模块。

## 2. 边界

- 账号、登录、识别码、云存档、签到、Toy 的删除属于 phase-03；本阶段保留这些模块，但不再让它们决定外观或多人入口。
- 不新增服务器；不修改房间协议、邀请码或房间服务；不自建联机。
- 不删除签到活动；活动款装饰在 phase-02 先全部开放。
- 不改变仓库脚本数量、加载顺序或 `index.html`。
- 不推送、不合并、不打标签。
